# Telegram-бот обратной связи

Бот собирает три оценки от 1 до 5, пишет их в SQLite, шлёт уведомления руководителю и формирует сводный отчёт по команде `/report`.

## Требования

- Python 3.10+ (рекомендуется актуальная ветка 3.x)
- Токен бота у [@BotFather](https://t.me/BotFather)
- У руководителя должен быть **username** в Telegram, и он хотя бы раз должен написать боту (или нажать Start), иначе отправка по `@username` может не дойти

## Установка зависимостей

```bash
cd telegram-feedback-bot
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Модуль `sqlite3` входит в стандартную библиотеку Python, отдельно его устанавливать не нужно.

## Настройка `.env`

1. Скопируйте пример конфигурации:

   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и укажите:

   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_USERNAME` — **логин руководителя без символа @** (например, `ivanov`, а не `@ivanov`)

## Запуск бота

```bash
source .venv/bin/activate   # если venv ещё не активирован
python bot.py
```

При первом запуске рядом с `bot.py` создаётся файл `feedback.db` с таблицей `feedback`.

## Команды

| Команда    | Описание |
|-----------|----------|
| `/start`  | Приветствие и подсказка |
| `/feedback` | Опрос из трёх вопросов (оценки 1–5) |
| `/report` | Сводный отчёт (только для руководителя — совпадение `ADMIN_USERNAME`) |
| `/help`   | Справка |
| `/cancel` | Прервать опрос |

## Изменение вопросов опроса

В файле `bot.py` отредактируйте список `SURVEY_ASPECTS` в начале файла. Количество пунктов должно оставаться **тремя**, чтобы совпадало с полями `aspect1`, `aspect2`, `aspect3` в базе.
