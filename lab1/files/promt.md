Создай Telegram‑бота на Python с использованием библиотеки python-telegram-bot.

Функционал бота:
- собирает обратную связь от пользователей через команды /start и /feedback;
- задаёт пользователю 3 вопроса с вариантами ответа (оценка от 1 до 5);
- сохраняет ответы в SQLite базу данных;
- по команде /report формирует и отправляет сводный отчёт руководителю (средние оценки, количество ответов);
- отправляет уведомление руководителю (@username) при получении каждого ответа;
- имеет команду /help с описанием функционала.

Команды бота:
- /start — приветственное сообщение и предложение пройти опрос;
- /feedback — запуск опроса;
- /report — получение сводного отчёта;
- /help — справка.

Формат ответов:
- приветственное сообщение: «Добро пожаловать! Я бот для сбора обратной связи. Используйте /feedback, чтобы пройти опрос, или /report, чтобы получить отчёт»;
- вопросы опроса: «Как вы оцениваете [аспект] по шкале от 1 (плохо) до 5 (отлично)?»;
- отчёт: «Сводный отчёт: [аспект 1]: средняя оценка — X, [аспект 2]: средняя оценка — Y, [аспект 3]: средняя оценка — Z. Всего ответов: N»;
- уведомления руководителю: «Получен новый ответ от [имя пользователя]».

Требования:
- бот должен быть простым и понятным;
- код должен быть хорошо прокомментирован;
- использовать SQLite для хранения данных (таблица feedback с колонками: id, user_id, username, aspect1, aspect2, aspect3, timestamp);
- добавить обработку ошибок (некорректный ввод, отсутствие данных);
- предусмотреть возможность легко изменить вопросы опроса.

Создай:
1. Файл bot.py с кодом бота.
2. Файл requirements.txt с зависимостями (укажи python-telegram-bot и sqlite3).
3. Файл README.md с инструкцией по запуску (установка зависимостей, настройка .env, запуск бота).
4. Файл .env.example с примером конфигурации (BOT_TOKEN=your_token_here, ADMIN_USERNAME=your_username_here).
